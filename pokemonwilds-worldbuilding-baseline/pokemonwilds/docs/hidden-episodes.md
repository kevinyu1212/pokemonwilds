# 괴담 반전형 교배기 히든 에피소드

도감의 부정적인 설명과 괴담을 뒤집어 포켓몬의 실제 본질을 밝힌다. 에피소드 해결 보상은 1회 한정 특별 개체이며, 교배기·숨겨진 특성·알그룹은 본가 데이터를 준수한다.

- **아공이** — 하이드로펌프 / 우격다짐: 물 계통의 드래곤으로 수로를 지키고 고립된 이들을 구한다.
- **델빌** — 길동무 / 긴장감: 죽음의 사자가 아니라 유독 에너지와 붕괴 위험을 감지해 안전한 곳으로 인도한다.
- **입치트** — 메탈버스트 / 우격다짐: 폭발 직전 장치를 몸으로 막아내며 경고한다.
- **깜까미** — HP회복 / 짓궂은마음: 보석 속 부정한 감정 데이터를 삼켜 정화한다.
- **드라꼰** — 기습 / 저주받은바디: 미래 도시 전자기기의 위험한 시간 신호를 추적·차단한다.

핵심은 외형이나 도감 설명이 존재의 본질을 결정하지 않는다는 것이다.
