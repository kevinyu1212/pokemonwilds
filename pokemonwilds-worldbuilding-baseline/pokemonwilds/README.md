# 《포켓몬스터 와일즈》

새로운 지방 **판도르**를 무대로 하는 포켓몬 팬 게임 기획 저장소입니다.

> 진정한 유대는 통제가 아니다. 공존은 모두를 하나로 만드는 것이 아니라, 서로 다른 존재가 함께할지 떨어져 있을지 스스로 선택할 수 있게 하는 것이다.

## 프로젝트 개요

- 배경: 미래 도시, 고대 생태계, 해저 왕국, 원시림, 화산 지맥, 빙하, 사막, 드래곤 협곡, 전쟁 폐허, 울트라스페이스가 공존하는 판도르 지방
- 핵심 질문: 인간과 포켓몬의 유대는 이해인가, 통제인가?
- 본편: 프롤로그 → 1부 판도르의 모험 → 2부 숨겨진 진실과 미래로의 모험
- 본편 이후: 아르세우스 특별 에피소드와 선택형 히든 에피소드
- 포켓몬 범위: 1세대부터 9세대까지

## 문서 안내

- `docs/worldbuilding.md`: 판도르의 기원, 고대 전쟁, 핵심 에너지
- `docs/story-flow.md`: 본편·특별 에피소드 전체 흐름
- `docs/factions-and-characters.md`: 조직, 세력, 주요 인물
- `docs/regions-and-gym-leaders.md`: 지역, 체육관, 비전 포켓몬 설계
- `docs/themes-and-legendary-pokemon.md`: 전설·환상 포켓몬과 주제
- `docs/easter-eggs.md`: 레드, 로켓단의 흔적, 열두 번째 밤의 꿈
- `docs/hidden-episodes.md`: 괴담 반전형 교배기 히든 에피소드
- `config/project-meta.json`: 프로젝트 메타데이터
- `scripts/Init-PokemonWilds.ps1`: Windows 개발 폴더 초기화
- `scripts/Commit-PokemonWilds.ps1`: PowerShell Git 커밋·푸시 보조 스크립트
